# Method figures

The PDF files are the primary, two-page vector figures. Each language also has
a self-contained HTML version with embedded fonts; download it and open it in a
browser. GitHub displays HTML source rather than running it.

| Language | PDF | HTML | README previews |
| --- | --- | --- | --- |
| English | [PDF](TagForge_core_principle.en.pdf) | [HTML](TagForge_core_principle.en.html) | [Workflow](TagForge_core_principle.en.page-1.png), [mechanisms](TagForge_core_principle.en.page-2.png) |
| 简体中文 | [PDF](TagForge_core_principle.zh-CN.pdf) | [HTML](TagForge_core_principle.zh-CN.html) | [流程](TagForge_core_principle.zh-CN.page-1.png)、[机制](TagForge_core_principle.zh-CN.page-2.png) |

PNG previews are rendered from the PDFs at 150 dpi specifically for inline
GitHub README display. All depicted sequences, structures and counts are
illustrative. See the [method overview](../docs/method-overview.md) for rules,
application scope and implementation references.
